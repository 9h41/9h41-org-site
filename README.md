# 9h41-org-site (GitHub Pages + 11ty)

Static website migration from Wix to GitHub Pages for `www.9h41.org`.

## Stack
- 11ty
- Plain HTML/CSS/JS
- GitHub Actions deployment to Pages

## Local development

```bash
npm install
npm run start
```

## Build

```bash
npm run build
```

## Deployment

- `main` / `master` -> `www.9h41.org`
- `staging` -> `stg.9h41.org`
